Indian Startup Funding Analysis Dashboard 🚀

This is one of my beginner data analysis projects where I explored Indian startup funding trends using Python and Streamlit. The project focuses on analyzing startup investments, investor activity, and sector growth through an interactive dashboard.

Features
Overall funding analysis (total funding, average investment, monthly trends)
Investor analysis to explore investment patterns
Startup-wise funding history and growth
Sector-wise funding comparison

Tech Stack:-
Python
Streamlit
Pandas
Matplotlib


Dataset
Indian startup funding data (2015–2020) containing startup names, investors, locations, funding types, and funding amounts.
dataset link:-
https://www.kaggle.com/datasets/sudalairajkumar/indian-startup-funding

What I Learned:-
This project helped me practice data cleaning, analysis, visualization, and dashboard building using real-world data.
